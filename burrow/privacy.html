Burrow — 隐私政策

最后更新：2026-04-30 · Version 1.0

概述

Burrow 是一款 iOS / iPadOS 客户端，用于通过你自行部署的 frp 服务器，从手机或平板访问自己家里（或别处）的电脑、NAS 等设备的 SSH / SFTP 服务。 Burrow 在设计上遵循数据最小化原则，不收集、不上传、不共享任何个人可识别信息。

我们不收集的信息

  • 我们不收集你的 frp 服务器地址、token、预共享密钥（secretKey）
  • 我们不收集你的 SSH 用户名、密码、私钥
  • 我们不收集你的命令收藏夹、Runbook、参数历史值
  • 我们不收集你通过 SSH / SFTP 传输的任何内容
  • 我们不使用任何第三方分析、广告、崩溃上报或追踪 SDK
  • App 内部不会向我们或任何第三方发起 HTTP/HTTPS 请求

本地数据

  • 连接配置（机器名、frps 地址、端口、用户名）：保存在 SwiftData（本地 SQLite）。
  • 敏感凭证（SSH 密码、私钥、frp secretKey、frp token）：保存在 iOS Keychain，加密级别 kSecAttrAccessibleAfterFirstUnlock。
  • 命令收藏夹、Runbook：保存在 SwiftData。
  • 参数历史值（如最近用过的 PID、文件路径）：保存在 UserDefaults。

所有数据不经过我们的任何服务器（我们也没有服务器）。 卸载 app 后，SwiftData 与 UserDefaults 数据会被 iOS 自动清除；Keychain 中的项也会随 app 卸载一并清除。

网络通信

App 建立的网络连接仅限：

  • 你在连接配置里填写的 frp 服务器（frps）—— 由 app 内嵌的 frpc 客户端发起；
  • 通过上述 frp 隧道建立的本地回环 SSH / SFTP 连接到你自己的设备。

除此之外不访问任何其它网络端点：没有统计 ping、没有 telemetry、没有广告 SDK 的回传。

权限

App 仅在你点击相关功能时请求以下权限，未使用的功能不会请求：

  • 文件访问（系统文件选择器）：仅在你主动点击"SFTP 上传"时弹出；我们只读你选中的那一个文件，用完即释放 security scope。
  • 系统分享表单：SFTP 下载完成后弹出，让你自行决定保存到 Files、相册或第三方 app。

App 不申请相册、定位、联系人、日历、健康等权限，无后台运行（无 Background Modes），无 VPN（无 NetworkExtension）。

第三方代码

App 使用以下开源库，均在本地执行、不做任何网络回传：

  • Citadel — SSH / SFTP 客户端（Swift）
  • fatedier/frp — frp 客户端（Go，通过 gomobile 编译嵌入）
  • SwiftNIO — 网络底层（Apple 官方）
  • swift-crypto — 加密（Apple 官方）

儿童隐私

App 面向有一定技术背景的开发者 / 运维 / NAS 用户，不以儿童为受众，也不会有意收集 13 岁以下儿童的任何信息。

政策变更

若未来隐私政策发生变更，我们将更新本页面并修改顶部的"最后更新"日期。 建议你定期查阅本页面以了解最新政策。
