Burrow — 지원

최종 업데이트: 2026년 4월 30일 · 버전 1.0

Burrow는 직접 운영하는 frp 서버를 통해 iPhone / iPad에서 집에 있는 컴퓨터, NAS 또는 기타 원격 기기에 안전하게 접속할 수 있는 클라이언트 앱입니다. frp 클라이언트(stcp visitor 모드)와 순수 Swift로 구현된 SSH / SFTP 클라이언트를 내장하며, 명령어 즐겨찾기 · Runbook · 파일 브라우저를 함께 제공합니다. 계정도, 백엔드도, 구독도 없이 한 번 구매로 평생 사용할 수 있습니다. 이 페이지에서는 지원 정보, 자주 묻는 질문 및 문의 방법을 안내합니다.

시스템 요구사항

  • 기기: iPhone 또는 iPad
  • OS: iOS / iPadOS 17.0 이상
  • frp 서버: 사용자가 직접 배포한 frps (v0.52 이상 권장)
  • 대상 기기: 집의 컴퓨터 / NAS에서 frpc(stcp visitee)와 SSH 서비스(기본 22번 포트)가 동작 중이어야 합니다.

시작하기

  1. 퍼블릭 IP가 있는 서버에 frps를 배포하고, bindPort와 auth.token을 기록해 둡니다.
  2. 접속하려는 기기(컴퓨터 / NAS)에서 frpc를 stcp visitee 모드로 실행하여 로컬 SSH(22번 포트)를 터널에 노출하고, 공유 비밀키 secretKey를 설정합니다.
  3. Burrow를 열어 새 연결을 만들고, frps 주소 · token · visitee 이름 · 동일한 secretKey · 대상 기기의 SSH 사용자명 · 비밀번호를 입력합니다.
  4. 연결을 탭하여 명령 셸 또는 SFTP 파일 브라우저로 진입합니다. 자주 쓰는 명령은 즐겨찾기 또는 Runbook으로 저장하여 한 번에 재사용할 수 있습니다.

자주 묻는 질문

  • 터널이 연결되지 않나요? frps 포트가 인터넷에서 도달 가능한지, token이 서버 설정과 일치하는지, 네트워크에서 frps 포트를 차단하지 않는지 확인해 주세요.
  • 대상 기기가 보이지 않나요? visitee 측 frpc 프로세스가 계속 실행 중이며, secretKey가 Burrow에 입력한 값과 일치하는지 확인해 주세요.
  • SSH 인증에 실패하나요? v1은 비밀번호 인증을 지원합니다. PEM 개인키 인증은 추후 버전에서 제공 예정입니다. 사용자명 · 비밀번호가 정확한지, 대상 sshd가 비밀번호 로그인을 허용하는지 확인해 주세요.
  • 앱이 백그라운드로 가면 터널이 끊어지나요? v1은 포그라운드에서만 터널을 유지합니다(NetworkExtension 미사용). 앱을 다시 포그라운드로 전환하면 재연결됩니다.
  • 데이터가 업로드되나요? 아니요. Burrow는 백엔드도, 계정도, 제3자 분석 / 추적 SDK도 없습니다. 모든 연결 정보와 명령은 기기 내에만 저장됩니다.
  • 구독제인가요? 아니요. Burrow는 한 번 구매하면 평생 사용할 수 있으며, 인앱 결제와 광고도 일절 없습니다.
