Burrow — 技术支持

最后更新：2026-04-30 · Version 1.0

Burrow 是一款让你自带 frp 服务器、在 iPhone / iPad 上安全访问家里电脑、NAS 或其它远端设备的客户端。 内嵌 frp 客户端（stcp visitor 模式）与纯 Swift SSH / SFTP 客户端，支持命令收藏夹、Runbook 与文件浏览。 无账号、无后端、无订阅 —— 买断即用。本页面提供技术支持信息、常见问题解答以及联系方式。

系统要求

  • 设备：iPhone 或 iPad
  • 系统：iOS / iPadOS 17.0 或更高版本
  • frp 服务器：由你自行部署的 frps（建议 v0.52 及以上）
  • 目标设备：家中电脑 / NAS 上运行的 frpc（stcp visitee）+ SSH 服务（默认 22 端口）

新手引导

  1. 在公网服务器上部署 frps，记下 bindPort 与 auth.token。
  2. 在你要访问的电脑 / NAS 上启动 frpc，使用 stcp visitee 模式将本机 SSH（22 端口）暴露给隧道，并设置预共享密钥 secretKey。
  3. 打开 Burrow，新建连接：填入 frps 地址、token、visitee 名称、相同的 secretKey，以及目标机器的 SSH 用户名 / 密码。
  4. 点击连接进入命令 Shell 或 SFTP 文件浏览器；常用命令可保存为收藏夹或 Runbook 一键复用。

常见问题

  • 隧道一直连不上？请确认 frps 端口在公网可达、token 与服务器配置一致、设备网络未屏蔽 frps 端口。
  • 看不到目标设备？请确认 visitee 端 frpc 进程仍在运行，且 secretKey 与 Burrow 中填写的一致。
  • SSH 认证失败？当前版本支持密码认证；PEM 私钥认证将在后续版本提供。请先确认用户名 / 密码正确，并确认目标 sshd 允许密码登录。
  • App 进入后台后断连？v1 仅在前台保持隧道（无 NetworkExtension）。请保持 Burrow 处于前台使用；切回前台可重新连接。
  • 数据会上传吗？不会。Burrow 没有后端、没有账号、没有第三方分析或追踪 SDK，所有连接信息和命令仅保存在本机。
  • 支持订阅吗？不支持。Burrow 采用一次性买断付费，无内购、无广告。
