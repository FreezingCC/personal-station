Burrow — プライバシーポリシー

最終更新: 2026年4月30日 · バージョン 1.0

概要

Burrow は、ご自身でデプロイされた frp サーバー経由で、自宅のパソコンや NAS などの SSH / SFTP サービスにアクセスするための iOS / iPadOS クライアントです。 Burrow はデータ最小化の原則に基づいて設計されており、個人を特定できるいかなる情報も収集・送信・共有しません。

収集しない情報

  • frp サーバーのアドレス、token、共通鍵（secretKey）を収集しません。
  • SSH のユーザー名、パスワード、秘密鍵を収集しません。
  • コマンドのお気に入り、Runbook、パラメータ履歴を収集しません。
  • SSH / SFTP で送受信される内容を収集しません。
  • 第三者の解析・広告・クラッシュレポート・トラッキング SDK を一切使用していません。
  • アプリ内部から当方や第三者への HTTP/HTTPS リクエストは一切発生しません。

ローカルデータ

  • 接続情報（マシン名、frps アドレス、ポート、ユーザー名）：SwiftData（端末内 SQLite）に保存されます。
  • 機微情報（SSH パスワード、秘密鍵、frp の secretKey および token）：iOS Keychain に kSecAttrAccessibleAfterFirstUnlock 保護クラスで保存されます。
  • コマンドのお気に入り、Runbook：SwiftData に保存されます。
  • パラメータ履歴（最近使用した PID やファイルパスなど）：UserDefaults に保存されます。

これらのデータは当方のサーバーを一切経由しません（そもそも当方はサーバーを保有していません）。 アプリをアンインストールすると、SwiftData と UserDefaults のデータは iOS により自動的に削除され、Keychain の項目もアプリと一緒に削除されます。

ネットワーク通信

本アプリが行うネットワーク通信は以下に限られます：

  • 接続情報に入力された frp サーバー（frps）への通信 — 内蔵された frpc クライアントが行います；
  • 上記の frp トンネルを介したご自身の機器への SSH / SFTP 通信。

これ以外のエンドポイントへのアクセスはありません。テレメトリ送信、解析、広告コールバックも一切ありません。

権限

本アプリは関連機能を操作したときのみ、以下の権限を要求します。未使用の機能では何も要求されません：

  • ファイルアクセス（システム標準のファイルピッカー）：「SFTP アップロード」を能動的にタップした際にのみ表示されます。当方は選択されたその 1 ファイルだけを読み取り、アップロード完了後はセキュリティスコープを直ちに解放します。
  • システム共有シート：SFTP のダウンロード完了後に表示され、ファイルを Files、写真、サードパーティアプリのいずれに保存するかをユーザー自身に選択していただけます。

本アプリは写真、位置情報、連絡先、カレンダー、ヘルスケア等の権限を要求しません。Background Modes も NetworkExtension（VPN）も使用していません。

サードパーティコード

本アプリは以下のオープンソースライブラリを使用しています。いずれも端末上でローカルに動作し、独自のネットワークコールバックを持ちません：

  • Citadel — SSH / SFTP クライアント (Swift)
  • fatedier/frp — frp クライアント (Go、gomobile で組み込み)
  • SwiftNIO — ネットワーク基盤 (Apple)
  • swift-crypto — 暗号化 (Apple)

お子様のプライバシー

Burrow は技術的な背景を持つ開発者・運用担当者・NAS ユーザーを対象としており、子供を主な利用者として想定していません。13 歳未満のお子様の情報を意図的に収集することはありません。
