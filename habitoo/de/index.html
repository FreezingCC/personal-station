Habitoo — Support

Zuletzt aktualisiert: 12.05.2026 · Version 1.0

Habitoo ist ein KI-Gewohnheitscoach für das iPhone. Sie sagen, was Sie tun wollen, und die KI verkleinert das Ziel auf eine Größe, die Sie heute Abend wirklich schaffen — und verknüpft es mit einem Moment, den Sie ohnehin täglich durchlaufen (Ihrem „Anker"). Am 1. jedes Monats erzeugt die App automatisch eine Auswertung auf Basis der Daten und Notizen, die Sie selbst eingetragen haben — keine leeren Motivationsphrasen, nur Ihre eigenen Belege. Diese Seite enthält Support-Informationen, häufige Fragen und Kontaktdaten.

Systemvoraussetzungen

  • Gerät: iPhone
  • Betriebssystem: iOS 17.4 oder höher
  • Netzwerk: Die KI-Funktionen (Zielverkleinerung, Anker-Vorschläge, Monatsrückblick) benötigen eine Internetverbindung. Alle anderen Funktionen funktionieren offline.

Erste Schritte

  1. Öffnen Sie die App und geben Sie die Gewohnheit ein, die Sie aufbauen möchten (zum Beispiel „mehr lesen", „dehnen", „meditieren").
  2. Die KI schlägt 4 Mikro-Starts vor — von einer 30-Sekunden-Mini-Handlung bis zur vollständigen Mikro-Gewohnheit unter 5 Minuten. Wählen Sie die Größe, die Sie heute Abend ohne Zögern erledigen würden.
  3. Wählen Sie einen Anker (einen Moment, an den die Gewohnheit gekoppelt wird): entweder eine feste Uhrzeit (zum Beispiel 07:30) oder eine bestehende Handlung (zum Beispiel „nach dem Morgenkaffee").
  4. Zum Anker-Zeitpunkt erhalten Sie eine lokale Benachrichtigung. Nach Erledigung haken Sie sie in der Today-Ansicht ab und schreiben optional eine kurze Notiz.
  5. Am 1. jedes Monats erzeugt die App automatisch einen Rückblick auf den Vormonat — mit Daten und Ihren Notizen, der die beste Woche und die Ausfallmuster hervorhebt.

Häufige Fragen

  • Die KI-Mikroziele gefallen mir nicht — was tun? Wählen Sie das kleinste, das Sie nie ablehnen würden, auch wenn es trivial wirkt. Wenn Sie das Thema ändern möchten, kehren Sie zur Eingabe zurück und formulieren Sie neu. Das Mikroziel lässt sich in der App jederzeit anpassen.
  • Ich erhalte keine Anker-Erinnerungen. Prüfen Sie die Benachrichtigungs-Erlaubnis: iOS-Einstellungen → Habitoo → Mitteilungen → Mitteilungen erlauben. Wenn Ihr Anker vom Typ „bestehende Handlung" ist (keine feste Uhrzeit), wird keine Benachrichtigung gesendet, weil der Moment nicht planbar ist — öffnen Sie nach dieser Handlung die App selbst.
  • Wann erscheint der Monatsrückblick? Automatisch am 1. jedes Monats. Für den Vormonat muss mindestens ein Eintrag vorliegen, damit die Generierung anläuft. Sie dauert wenige Sekunden bis eine halbe Minute; warten Sie auf das Ergebnis.
  • Warum gibt es keinen „N-Tage-Streak"-Zähler? Bewusste Entscheidung. Studien zeigen, dass Streak-Zähler die Hauptursache für den Abbruch sind — ein einziger verpasster Tag fühlt sich wie kompletter Misserfolg an. Habitoo zeigt stattdessen die Erfolgsquote über 30 / 100 Tage und eine Schwierigkeits-Heatmap, damit Sie das Gesamtmuster sehen statt von einer einzelnen Zahl bestraft zu werden.
  • Kann ich mehrere Gewohnheiten verfolgen? Die kostenlose Version unterstützt eine Gewohnheit mit dem vollständigen KI-Zyklus. Mehrere Gewohnheiten gibt es in der Pro-Version (in Entwicklung). In der App können Sie sich unter Einstellungen → Pro auf die Warteliste setzen.
  • Wird mit iCloud synchronisiert? In dieser Version nicht. Alle Daten werden lokal auf Ihrem Gerät gespeichert. Geräteübergreifende Synchronisation ist eine geplante Pro-Funktion.
  • Was passiert mit meinen Daten bei Deinstallation? Lokale Daten (Gewohnheiten, Erledigungen, Notizen) werden bei der Deinstallation durch iOS entfernt. Ihre Warteliste-E-Mail (falls eingereicht) liegt auf unserem Backend — schreiben Sie uns für eine Löschung.
  • Die KI gab eine seltsame oder nutzlose Antwort. Schreiben Sie uns bitte mit Ihrer Eingabe und der erhaltenen Antwort. Die KI-Prompts werden auf Basis echter Rückmeldungen iteriert.
  • Kann ich eine Notiz bearbeiten oder löschen? Ja. Sowohl in der Today-Ansicht als auch im Detail eines Eintrags sind beide möglich.
  • Werden meine Gewohnheitsnamen / Journaltexte zum Training der KI verwendet? Nein. Wir senden bei jedem KI-Aufruf (Zielverkleinerung, Anker-Vorschlag, Coach-Check, Monatsrückblick) nur das Minimum an Daten an unseren KI-Anbieter (MiniMax). Laut unserer Vereinbarung werden diese Daten nicht für Modelltraining genutzt. Siehe Datenschutzerklärung.

Bekannte Einschränkungen und Roadmap

  • v1.0 unterstützt ausschließlich das iPhone — kein iPad, Mac oder Vision Pro. Plattformerweiterung ist auf der Roadmap, ohne festen Termin.
  • In dieser Version gibt es kein Kontosystem, keine geräteübergreifende Synchronisation und keinen Datenexport. Diese Funktionen folgen mit Pro.
  • Der Monatsrückblick liegt in v1.0 nur als Text vor; eine teilbare visuelle Karte ist eine geplante Pro-Funktion.
